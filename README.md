# Tidal Force Simulation - Educational Edition

An interactive 3D simulation designed to help students visualize and understand the gravitational interactions that cause tides on Earth. Created to help others learn after a challenging exam experience!

## 🚀 Live Demo
**[Click here to open the simulation](https://electron22x.github.io/tides-sim/)** (Mobile & PC friendly)

## ✨ Key Features
- **3D Interactive Visualization**: Rotate, zoom, and observe the tidal bulge in real-time.
- **Mobile Responsive**: Fully optimized for smartphones and tablets (touch gestures supported).
- **Educational Presets**:
  - **Mercury Orbit**: See extreme tides caused by close proximity to the Sun.
  - **Spring & Neap Tides**: Understand the effects of Sun-Moon alignment.
- **Real-time Data**: Live charts tracking tidal height and gravitational force.
- **Teaching Tools**: Replay features, concept annotations (hover on PC), and a built-in practice quiz.
- **Performance Optimized**: Automatically scales graphics for lower-end devices.

## 📖 How to Use
- **Drag**: Rotate the 3D view.
- **Scroll/Pinch**: Zoom in or out.
- **Settings Sidebar**: Access simulation controls, presets, and data charts.
- **Replay**: Watch the last 10 seconds of simulation to analyze movements.

## 🛠️ Deployment
This project is hosted using GitHub Pages. If you'd like to run it locally:
1. Clone this repository.
2. Open `index.html` in any modern web browser.
